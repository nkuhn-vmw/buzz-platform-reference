# Documentation artwork

The SVG diagrams are editable, repository-owned architecture illustrations. Their labels describe this reference implementation; companion Mermaid sources are embedded in [architecture.md](../architecture.md).

`hero.webp` is original AI-generated artwork created for this reference on 2026-10-30 and converted to WebP with metadata removed. Its design brief was a text-free midnight-navy scene with cyan, purple, and teal connections between local desktop message panels and hosted platform blocks. It is decorative artwork, not a screenshot or evidence of running software.

The JPEG screenshots are authentic captures of the isolated reference desktop. They use a neutral workshop profile and example project content. Sign-in tokens, private identity details, and deployment credentials are excluded. These images illustrate the tested interface; desktop versions may differ.

`channel-members.jpg` and `agent-thread.jpg` were captured on 2026-10-31 from the live TMM reference desktop. The thread shows an actual request, hosted-agent reply, and tool nonce; it is not a mockup.

`agent-mentions.jpg` and `researcher-thread.jpg` show the configured agent directory and a real built-in-runtime conversation after owner-only directory registration on 2026-10-31.
